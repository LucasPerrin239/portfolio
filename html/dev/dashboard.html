Dans le cadre d'un projet de fin d'année, nous avions pour objectif de créer un tableau de bord météo. Avec la base données qui nous était fournie, nous devions sélectionner les informations pertinentes à visualiser pour informer les utilisateurs sur la météo du département.

L'objectif était de manipuler le langage MySQL ainsi que php pour récupérer et manipuler les données, puis ensuite les intégrer dans des graphiques grâce à du javascript, afin de le visualiser sur la page pour l'utilisateur.
Nous pouvions également rendre la page interactive , ce qui est le cas car on peut choisir les données à visualiser. C'est-à-dire la ville, l'intervalle de date, ou bien la saison.

(Cette page n'avait pas pour but d'être responsive, il est donc mieux de la visiter sur PC)
